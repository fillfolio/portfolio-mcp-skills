## Submission facts

- Fillfolio publishes MIT-licensed contracts, client examples and helpers for its hosted read-only MCP service. The public contract repository does not contain the private hosted implementation.
- The skill files are free and MIT licensed. Most workflows require eligible Fillfolio account access, an accepted OAuth client and relevant read permissions. The public connection catalog needs no account. Spending and budgets have separate permissions.
- The remote endpoint is `https://fillfolio.com/api/mcp`, using Streamable HTTP and OAuth. Tool reads return stored records and do not trade, transfer, edit data or refresh providers.
- Portable skill format support and successful authentication in a particular host are separate claims. See [Client setup](client-setup.md) and [validation evidence](validation.md).
- Use the Fillfolio GitHub identity for public contributions. Keep credentials, reviewer access and account data out of contributions and screenshots.
